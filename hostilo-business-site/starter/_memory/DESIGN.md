# Design

- Colours: ink #14202b, muted #5d6b78, lines #dde3ea, background #ffffff, soft background #f3f6f9, accent #0f5c8a (white text on accent).
- Font: system UI stack, 17 px body, line height 1.65; headings bold, hero h1 clamp(1.8rem, 4vw, 2.8rem).
- Layout: content width 1120 px with 16 px side gutters; border radius 10 px.
- Components: header (logo, menu, language switcher PL · EN), hero with one button, news item card (date, title, summary, optional image), contact form (labels above fields), footer with company data.
- Images: WebP, max 2000 px wide, 16:9 for news, always alt text and width/height.
- No dark mode.
